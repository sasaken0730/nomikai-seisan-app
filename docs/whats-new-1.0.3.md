# What's New 下書き（v1.0.3 / App Store Connect用）

App Store Connect の「このバージョンの新機能」欄に貼り付ける想定の下書きです。文字数・トーンは申請時に調整してください。

## 案A（機能寄り・推奨）

```
・参加者の入力を1人1行にすっきりまとめました。名前はまとめて入力でき、過去のメンバーからも複数まとめて選べます
・遅れてきた人、主役、あまり飲まなかった人など、その会だけ金額を固定できるようになりました（出席表のセルを長押し）
・精算結果を「表でコピー」できるようになりました。ExcelやGoogleスプレッドシートに貼ると、そのまま表になります
・「幹事」は端数をまとめて負担する人であることが分かるように表記を見直しました
・ご意見・ご要望を送れる欄を結果画面に追加しました（任意）
・はじめて使った端末で、過去のメンバーが表示されないことがある問題を修正しました
```

## 案B（短め）

```
参加者の入力を1人1行に整理し、名前のまとめて入力に対応しました。遅刻や主役など、その会だけ金額を固定することもできます。精算結果はスプレッドシートに貼れる「表でコピー」に対応しました。
```

## 補足（申請時の参考・アプリ内には表示しない）

- 参加者入力の1行化は、1人あたり4行・6人で24行になっていたスクロール負荷を解消するため。役職デフォルトが「その他役職」で年次欄が全員に開く状態だったのが主因
- 会ごとの固定額は、従来の「参加者単位の固定額」が実際の使われ方（遅刻・主役・下戸はいずれも特定の会の事情）と合っていなかったことへの対応。旧データは会ごとの指定が無い場合のみ従来どおり按分されるため、過去の精算結果は変わらない
- 「表でコピー」はTSV。HTML形式はiOSでの挙動が保証されず、LINE経由で書式が落ちるため平文TSVを選択
- フィードバック欄は、保存率やリピート率といった数値だけでは拾えない定性的な声を集めるため。氏名・連絡先は受け取らない
- 「過去のメンバーが出ない」は `getDeviceId()` の競合。複数画面から並行で呼ばれ、インストール直後に別々の端末IDが生成されることがあった
