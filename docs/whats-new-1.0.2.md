# What's New 下書き（v1.0.2 / App Store Connect用）

App Store Connect の「このバージョンの新機能」欄に貼り付ける想定の下書きです。文字数・トーンは申請時に調整してください。

## 案A（機能寄り・やや詳しめ）

```
・精算が完了すると自動で履歴に保存されるようになりました。保存ボタンを押す必要はありません
・ホーム画面に「最近のルーム」を表示。精算完了／作業中がひと目でわかります
・履歴から「このメンバーをベースに新しく作る」で、前回と同じメンバーの精算を1タップで始められます
・はじめての方向けに「傾斜精算とは？」の説明を追加しました
・年次の入力例と、未入力の場合の扱いを表示するようにしました
・金額の入力を忘れているときに、そっとお知らせするようにしました
```

## 案B（短め）

```
精算が完了すると自動で履歴に保存されるようになりました。ホーム画面では最近のルームを一覧でき、履歴からは前回と同じメンバーで新しい精算を1タップで始められます。そのほか、はじめての方向けの説明や入力のヒントを追加しました。
```


## 案C（2026-11 追加分を含む最新版・推奨）

```
・参加者の入力を1人1行にすっきりまとめました。名前はまとめて入力でき、過去のメンバーからも複数まとめて選べます
・精算が完了すると自動で履歴に保存されます。保存ボタンを押す必要はありません
・遅れてきた人、主役、あまり飲まなかった人など、その会だけ金額を固定できるようになりました（出席表のセルを長押し）
・精算結果を「表でコピー」できるようになりました。ExcelやGoogleスプレッドシートに貼ると、そのまま表になります
・ホーム画面に「最近のルーム」を表示。履歴からは前回と同じメンバーで1タップで始められます
・はじめての方向けの説明と入力のヒントを追加しました
・ご意見・ご要望を送れる欄を結果画面に追加しました（任意）
```

## 案D（短め・最新版）

```
参加者の入力を1人1行に整理し、名前のまとめて入力に対応しました。遅刻や主役など、その会だけ金額を固定することもできます。精算結果はスプレッドシートに貼れる「表でコピー」に対応。精算は完了すると自動で履歴に保存されます。
```

## 補足（申請時の参考・アプリ内には表示しない）

- 自動保存は、v1.0.1 のUI改善（目立つ保存ボタン・下書き自動保存）後も外部ユーザーの保存率が0〜3%のままだったことへの構造的な対策です。「保存ボタンを押す」前提をやめ、精算が成立した時点（参加者2人以上・合計金額 > 0）で自動保存します
- 「このメンバーをベースに新しく作る」はリテンション対策（現状7% → 目標20%）です
- 傾斜精算の説明ポップアップと年次入力のヒントは、年次入力率（現状67.6%）を上げ、傾斜アプリなのに等分割り勘になっている状態を減らすのが目的です
- 金額未入力のヒントは、イベント0件のまま放棄されるルーム（現状5.6%）の救済が目的です
- App Store のレビュー依頼（精算完了3回以上・前回から30日以上）を追加していますが、ユーザー向けの告知は不要なため記載していません

### 2026-11 追加分の補足

- 参加者入力の1行化は、1人あたり4行・6人で24行になっていたスクロール負荷を解消するため。役職デフォルトが「その他役職」で年次欄が全員に開く状態だったのが主因
- 会ごとの固定額は、従来の「参加者単位の固定額」が実際の使われ方（遅刻・主役・下戸はいずれも特定の会の事情）と合っていなかったことへの対応
- 「表でコピー」はTSV。HTML形式はiOSでの挙動が保証されず、LINE経由で書式が落ちるため平文TSVを選択
- フィードバック欄は、保存率やリピート率といった数値だけでは拾えない定性的な声を集めるため
