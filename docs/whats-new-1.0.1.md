# What's New 下書き（v1.0.1 / App Store Connect用）

App Store Connect の「このバージョンの新機能」欄に貼り付ける想定の下書きです。文字数・トーンは申請時に調整してください。

## 案A（機能寄り・やや詳しめ）

```
・アプリのデザインを一新しました。アイコンに合わせた紺と金を基調にしています
・入力中の内容を自動保存するようになりました。うっかり保存を忘れても、ホーム画面の「作業中の精算」からすぐ再開できます
・精算結果を1タップでコピーできるようになりました。LINEやメモアプリに貼り付けると、表形式で見やすく共有できます
・「履歴に保存」ボタンを大きく分かりやすくしました
・傾斜設定（倍率）の意味がひと目でわかるよう説明を追加しました
・ボタンやプルダウンのタップ範囲を広げ、操作しやすくなりました
・細かい操作感を改善しました（タップ時の触覚フィードバックなど）
```

## 案B（短め）

```
アプリのデザインを一新し、アイコンに合わせた紺と金を基調にしました。精算の入力内容が自動保存されるようになり、途中で閉じても安心して再開できます。精算結果はワンタップでコピーして共有可能に。そのほか操作性を細かく改善しました。
```

## 補足（申請時の参考・アプリ内には表示しない）

- 自動保存とホーム画面の再開バナーは、実ユーザーデータで判明した「保存し忘れ」への対策として追加した機能です
- 「傾斜設定の説明」「タップ範囲拡大」は初見ユーザーの分かりにくさ解消が目的です
- デザイン刷新は、アプリアイコン（紺＋金＋白）と画面配色（従来はオレンジ基調）の世界観が合っていなかったための統一。レイアウトはそのまま、色のみの変更
